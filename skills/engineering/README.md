# Engineering Skill

**Status:** Active  
**Version:** 0.1

This skill helps convert accepted design into structured implementation plans.

## Workflow

1. confirm constraints and accepted decisions;
2. decompose into subsystems or modules;
3. define dependencies;
4. note risks and failure states;
5. define implementation sequence;
6. propose review gates.

## Output

Engineering output should include:

- system boundaries;
- module responsibilities;
- dependencies;
- tradeoffs and risks;
- implementation notes.
