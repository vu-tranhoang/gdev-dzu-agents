# Example Project Workflow

This is a sample workflow pattern showing how work transitions between roles.

```text
Research Agent
  ↓
Game Designer / Design Proposal
  ↓
Technical Architect / Architecture Review
  ↓
Developer / Implementation
  ↓
Reviewer / Quality Review
  ↓
Human Project Owner / Decision or Acceptance
```

This is illustrative only. Real projects may add or remove stages according to accepted governance.
