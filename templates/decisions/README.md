# Decision Templates

This directory stores accepted decisions and rationale.

## Recommended files

```text
templates/decisions/
├── decision-record-template.md
├── architecture-decision-template.md
└── tradeoff-template.md
```

## Required fields

- title;
- status;
- context;
- decision;
- rationale;
- consequences;
- alternatives considered;
- owner or approver.
