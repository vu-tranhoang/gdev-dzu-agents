# Templates

This directory contains reusable templates for downstream game projects built with `gdev-dzu-agents`.

## Structure

```text
templates/
├── specs/
├── research/
├── decisions/
├── architecture/
└── README.md
```

## Purpose

- `specs/` — story, requirement, and specification templates
- `research/` — research briefs and evidence capture templates
- `decisions/` — accepted decisions and rationale records
- `architecture/` — architecture docs and system design templates

Use these as starting points, not as project-specific requirements.

## Naming

Prefer clear, consistent naming such as:

- `SPEC-001-feature-name.md`
- `RESEARCH-013-market-analysis.md`
- `DEC-004-save-system.md`
- `ARCH-002-player-movement.md`
