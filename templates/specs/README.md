# Specs Templates

This directory is intentionally generic and project-agnostic.

## Recommended files

```text
templates/specs/
├── story-template.md
├── requirements-template.md
├── analysis-template.md
├── design-template.md
├── tasks-template.md
└── tests-template.md
```

## Example usage

Use these templates when a new Story or feature begins. The templates should preserve:

- objective;
- scope;
- constraints;
- assumptions;
- risks;
- acceptance criteria;
- open questions.
